### 4.6. `docker-yolo.yml` y API FastAPI

Crear el servidor FastAPI (`$HOME/proyecto/yolo/app.py`):
```python
import os, io, torch
from fastapi import FastAPI, File, UploadFile
from PIL import Image
from ultralytics import YOLO

app = FastAPI(title="YOLO Vision API")
model = YOLO(os.getenv("YOLO_MODEL", "yolo11n.pt"))

@app.get("/health")
def health():
    return {"status": "ok", "gpu": torch.cuda.is_available()}

@app.post("/detect")
async def detect(file: UploadFile = File(...), conf: float = 0.25):
    image = Image.open(io.BytesIO(await file.read())).convert("RGB")
    result = model.predict(image, conf=conf, verbose=False)[0]
    detections = [
        {
            "class": result.names[int(box.cls)],
            "confidence": round(float(box.conf), 4),
            "box_xyxy": [round(v, 1) for v in box.xyxy[0].tolist()]
        }
        for box in result.boxes
    ]
    return {"count": len(detections), "detections": detections}
```[cite: 2, 3]

## 5. Orquestación, Arranque y Pruebas

### 5.1. Script de Despliegue Secuencial (`$HOME/proyecto/start.sh`)
```bash
cat > $HOME/proyecto/start.sh <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
cd "$(dirname "$0")"

docker network inspect red-ia >/dev/null 2>&1 || docker network create --driver bridge red-ia

for svc in ollama rag searxng comfyui yolo openwebui hermes-agent opencode; do
  echo ">>> Desplegando servicio: $svc"
  docker compose --env-file .env -f "docker-${svc}.yml" up -d --build
done

echo ">>> Estado actual de la pila de IA:"
docker ps --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'
EOF

chmod +x $HOME/proyecto/start.sh
```[cite: 3]

## 6. Resolución de Problemas Frecuentes (Troubleshooting)

### 🚨 1. Error `Permission Denied` en volúmenes o comandos Docker
* **Causa:** El usuario del sistema no pertenece al grupo `docker` o el contenedor escribe archivos con UID/GID distintos[cite: 3].
* **Solución:**
  ```bash
  sudo usermod -aG docker $USER
  sudo chown -R $USER:$USER $HOME/openwebui $HOME/hermes $HOME/comfyui
  sudo chown -R 977:977 $HOME/searxng
  ```[cite: 3]

### 🚨 2. Error CUDA: `Out of Memory` (OOM)
* **Causa:** Saturación de VRAM por mantener múltiples modelos pesados cargados en memoria a la vez[cite: 3].
* **Solución:**
  Verificar qué modelo está cargado en Ollama y forzar su descarga:
  ```bash
  docker exec -it ollama ollama ps
  docker exec -it ollama ollama stop <nombre_modelo>
  ```[cite: 3]
  Asegurarse de que en `.env` la variable `COMFYUI_ARGS` incluye `--lowvram`[cite: 3].

### 🚨 3. Open WebUI no detecta Ollama ni SearXNG
* **Causa:** Un contenedor intentando conectarse a `localhost` en lugar de resolver por el DNS de la red `red-ia`[cite: 2, 3].
* **Solución:**
  Probar conectividad desde el contenedor de Open WebUI:
  ```bash
  docker exec openwebui curl -s http://ollama:11434/api/tags
  docker exec openwebui curl -s "http://searxng:8080/search?q=test&format=json"
  ```[cite: 2, 3]

## 7. Plan de Backups Automáticos (`$HOME/proyecto/backup.sh`)

Crear el script de copias de seguridad de datos de configuración y estado (excluyendo modelos pesados reinstalables)[cite: 2, 3]:

```bash
cat > $HOME/proyecto/backup.sh <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
DEST="$HOME/backups"
FECHA=$(date +%Y%m%d_%H%M)
mkdir -p "$DEST"

echo ">>> Deteniendo servicios persistentes..."
for svc in openwebui rag hermes-agent opencode; do
  docker compose --env-file $HOME/proyecto/.env -f "$HOME/proyecto/docker-${svc}.yml" stop
done

echo ">>> Creando archivo comprimido..."
tar -czf "$DEST/config_${FECHA}.tar.gz" -C "$HOME" \
  openwebui rag hermes opencode searxng/config yolo proyecto/.env proyecto/*.yml

echo ">>> Reiniciando servicios..."
for svc in rag openwebui hermes-agent opencode; do
  docker compose --env-file $HOME/proyecto/.env -f "$HOME/proyecto/docker-${svc}.yml" start
done

# Retener solo los últimos 7 backups
ls -1t "$DEST"/config_*.tar.gz | tail -n +8 | xargs -r rm --
echo "Backup finalizado exitosamente: $DEST/config_${FECHA}.tar.gz"
EOF

chmod +x $HOME/proyecto/backup.sh
```[cite: 3]

Para automatizar la copia cada domingo a las 3:00 AM, agregar a `crontab -e`:
```text
0 3 * * 0 /home/usuario/proyecto/backup.sh >> /home/usuario/backups/backup.log 2>&1
```[cite: 3]
